## Склейка «глазами покупателя» (Озон)

Покупатель выбирает по картинке, потом по составу, потом размер (он должен быть внутри карточки), и смотрит на цену и наличие.
Сейчас группа подбирается по бренду, типу и признаку, но не по виду товара.

1. **Цвет и рисунок.** В `dim_fabric` есть `color`, `pattern`, `audience`, `weave`. Связать дизайн с тканью и внутри ветки
   склеивать близкие по цвету и рисунку. Мягкое правило, не жёсткое. Сначала проверить, у скольких дизайнов есть связь с `dim_fabric`.
2. **Ценовой коридор.** Не клеить в одну карточку дизайны с большой разницей цены (источник `ozon_prices`).
3. **Наличие и продажи.** Не тащить в карточку дизайны, которые не продаются и портят её. Порог остатка уже есть
   (`[stock] min_total`), здесь речь о более тонком отсечении.
4. **Порядок внутри группы.** Хиты первыми: первую позицию покупатель видит первой. Это про отображение, а не про состав.

## Открытые решения

- Порог наличия тканей на Озоне: «итого больше 1» (сейчас, `min_total = 2`) или «хотя бы 1» (`min_total = 1`). Разница 63 против 86 дизайнов.
- Комплекты по размеру 4/5/6/8: рекомендация не делить (дизайн остаётся целым по размеру).
- Остаток смеси признаков 3,2% (123 артикула из 3846): малые ветки (рюши, пуговицы, уличные шторы, кант) растворяются в «Обычных».
  Варианты: снизить порог отделения (сейчас `split_up = 10`, `merge_down = 8`) либо оставлять малые ветки малыми группами.
- Проверка реального бренда Озона в сборщике (сейчас бренд только по префиксу артикула). Менять бренды на Озоне нельзя до ответа поддержки.
